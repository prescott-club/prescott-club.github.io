PRESCOTT CLUB — SITIO WEB INICIAL

1. Extrae el ZIP.
2. Sube TODOS los archivos y la carpeta assets al repositorio prescottclub.github.io.
3. En GitHub abre Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Branch: main / (root). Guarda.
6. Espera unos minutos y abre https://prescottclub.github.io/

IMPORTANTE:
- Esta es una primera versión estática multipágina.
- El carrito guarda los productos en el navegador.
- El botón de pedido abre la aplicación de correo con el pedido preparado; el usuario debe pulsar Enviar.
- No hay pagos en línea.
- /admin.html es solo una pantalla informativa. No existe todavía un panel administrativo seguro.
- Para autenticación real, edición de productos y envío automático de pedidos hace falta conectar un backend (por ejemplo Supabase/Firebase) y configurar permisos.
- Las fotos de producto actuales son marcadores provisionales; reemplazar cuando se reciban las fotos oficiales.
- El logo de referencia enviado se conserva en assets, pero el encabezado usa texto y Dancing Script para mantener el eslogan nítido y adaptable.
